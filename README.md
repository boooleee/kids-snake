# 🍬 糖果贪吃蛇 · Three.js

一个**儿童向、糖果风**的 3D 贪吃蛇。单文件、无构建、开浏览器就能玩。
用 Three.js 做 3D 渲染，emoji 食物 + 粒子 + 音效——小朋友玩得开心，大朋友也有得琢磨。

> 🌐 在线玩：<https://boooleee.github.io/kids-snake/>

## ✨ 特色

- 🎨 糖果配色 + 彩虹蛇身，四色柔和棋盘
- 🍎 7 种食物差异化加分，⭐ 幸运星限时 7 秒（吃不到就跑掉）
- 🧩 4 种道具：慢动作 / 护盾 / 透视 / 冲刺
- ⚡ 连击系统（4 秒内保持，断了归零，每 5 连弹提示）
- 🏅 9 枚成就徽章，本地持久化
- 📤 一键生成「战绩卡」（Canvas 合成，可保存/复制）
- 🔊 WebAudio 小音效（可关），🌈 彩虹蛇身 · 粒子 · 飘字
- 📷 自适应正交相机：格子永远正方形、棋盘让开面板，手机桌面都不挤
- 🌐 three.js 多 CDN 兜底（国内 jsDelivr / npmmirror 优先，海外 unpkg 殿后），加载失败有友好提示
- ⏸ 切后台自动暂停；最高分本地保存

## 🎮 玩法

- 控制小蛇吃食物、变长；**吃得越多，速度越快**。
- 16×16 棋盘，两种模式：
  - 🌈 **轻松模式**：撞墙穿过去，慢慢找手感
  - 🔥 **挑战模式**：撞墙就结束，冲高分
- 撞到**自己**同样结束（护盾能挡一次）。

## 🏅 成就徽章（9 枚，本地保存）

🎮 初次上路 · 🥇 金蛇(60分) · 👑 糖果王(100分) · 🍖 大胃王(一局吃 20 个) · ⚡ 连击大师(10 连) · ⭐ 摘星者(吃到幸运星) · 🛡 护身使者(护盾挡过) · 🏆 满盘通关 · 🔥 挑战摘星(挑战模式 60 分)

## 🚀 运行

直接打开 `index.html` 即可（需联网加载 three.js）。或本地起个静态服务：

```bash
python3 -m http.server
# 浏览器打开 http://localhost:8000/index.html
```

## 🧱 技术

- 单文件 `index.html`（内联 CSS + ES 模块 JS），无框架、无构建步骤
- Three.js (r160)：正交相机 + 精灵 / Canvas 纹理 + 粒子
- WebAudio 生成音效（不依赖音频文件）
- `localStorage` 存最高分 / 成就 / 静音开关
- `window.__candy` 调试钩子（供自动化测试读取状态）
